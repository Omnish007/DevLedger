## Source-level notes

- Primary UI routes are managed using the renderer's `ViewId` state and app shell; the repository does not use a conventional React Router route table for these workspaces.
- Quick Capture is a separate Electron window, not a normal main-window page.
- FTS5 is a local search capability; semantic/AI search depends on optional local integration and is not required for the baseline offline E2E suite.
- The project archive import/export workflow is not interchangeable with encrypted full-workspace backup/restore.
- A visible button or API name is not by itself proof of a complete user flow. The coverage matrix differentiates UI E2E coverage from lower-layer service tests and untested scenarios.
